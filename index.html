How To Download Addon

Follow these steps to download the Betafied Addon for Minecraft Bedrock Edition.


  1. Click the Download Button
    Click "Download Addon" button below to get the latest version directly. Download Addon
  2. Save the File
    Wait for the download to finish. You should have a file ending in .mctemplate.
  3. Import to Minecraft
    Double click the downloaded .mctemplate file to automatically launch Minecraft and import the addon.


(Requires Minecraft Bedrock Edition)

Join the Discord for more info and questions

How To Update

If you already have a previous version of Betafied, follow these steps to update safely.


  1. Join the Discord
    Join our community server: Betafied Discord.
  2. Download the Update
    Go to the #downloads channel and download the latest .mcaddon file.
  3. Prepare Your World
    Open Minecraft and go to Create New World > Owned section.
  4. Unlock the Template
    Select your Betafied world template and unlock the template to make it editable.
  5. Remove Old Packs
    In the world settings, go to Resource Packs & Behavior Packs and remove the old "Betafied" versions.
  6. Install New Version
    Import and activate the new .mcaddon you downloaded to update your world.
